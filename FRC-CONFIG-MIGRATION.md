## 5. Issues to resolve before building

### 5.1 Custom metadata fields exist only in the staging database

**This is the most likely thing to break the migration.**

No file under `config/registries/` differs from stock 9.2, yet
`submission-forms.xml` references fields that are not in any stock registry:

- `dc.relation.isreferencedbyDuke`, `…Hathi`, `…Google`, `…Gale`,
  `…Delaware`, `…Avalon`, `…Archive`, `…HeinOnline`
- `dc.relation.exceptions`
- `dc.description.lawtext`, `dc.description.summary`
- `local.editorial.note` (and the whole `local` schema)

These were created through the admin UI, so they live in the staging database
only. On the new instance, either:

- export them from staging and add them to `config/registries/local-types.xml`
  (loaded by `./dspace registry-loader`), or
- recreate them via the admin UI before enabling the custom submission forms.

Until then, form validation will fail and submissions will error.

### 5.2 A live reCAPTCHA secret is inside this git repository

`dspace/config-copy/config/dspace.cfg` contains
`google.recaptcha.key.secret` in plaintext, in an untracked directory inside a
git repo with two remotes.

- Add `dspace/config-copy/` to `.gitignore` before any commit.
- The secret is deliberately redacted from this document — read it from staging.
- Rotate the key if this tree is ever pushed.

The same `dspace.cfg` also carries DB and mail settings; treat the whole
`config-copy` directory as sensitive.

### 5.3 Staging has no `local.cfg`

Only `local.cfg.EXAMPLE` is present. Every site setting was edited directly
into `dspace.cfg`, which is why this comparison runs to 177 lines.

**Recommendation for the new instance:** leave `dspace.cfg` pristine and put
everything from section 2 into `local.cfg`. Upgrades then become a file copy
instead of a hand-merge. The two `include` lines are the one exception — those
belong in `dspace.cfg` or can be replaced by `local.cfg` entries directly.

### 5.4 Post-deployment steps these changes require

| Change | Required action |
|---|---|
| Browse index changes | `./dspace index-discovery -b` |
| `discovery.xml` facet changes | `./dspace index-discovery -b` |
| New vocabularies (`jurisdictions`, replaced `srsc`) | Restart Tomcat |
| `metadata.hide.*` changes | Restart Tomcat — hidden-field set is cached at startup |
| CleanMetadata registration | Restart Tomcat |
| `usage-statistics.dbfile` | Copy `GeoLite2-City.mmdb` to the new host |
| ImageMagick thumbnails | Install ImageMagick; verify `/usr/bin/convert` exists |
| `AuthenticatedUsers` special group | Create the group if it does not exist |
